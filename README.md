## Learning Approach

Each notebook follows a topic-wise learning approach:

1. **Understand** – Learn the concept and definition.
2. **Demonstrate** – Understand the concept using a simple example.
3. **Implementation** – Implement the concept using Python or SQL code.

This approach helps build both theoretical understanding and practical programming skills.

The objective of Sprint 1 is to develop a strong foundation in **Python and SQL**, understand important programming concepts, and gain hands-on experience by implementing the concepts in Jupyter Notebooks.
